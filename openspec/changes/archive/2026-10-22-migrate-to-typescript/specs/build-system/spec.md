# Spec Delta

## ADDED Requirements

### Requirement: Проверка типов при сборке
Production-сборка SHALL включать проверку типов TypeScript перед сборкой бандла: при ошибке типов сборка SHALL завершаться ошибкой без создания `dist/`. Также SHALL быть доступен отдельный скрипт `npm run typecheck` для проверки типов без сборки.

#### Scenario: Ошибка типов ломает сборку
- **WHEN** в исходниках есть ошибка типов и выполняется `npm run build`
- **THEN** сборка завершается с ошибкой компилятора типов, `dist/` не пересоздаётся

#### Scenario: Отдельная проверка типов
- **WHEN** выполняется `npm run typecheck`
- **THEN** компилятор TypeScript проверяет исходники без создания файлов вывода и завершается с кодом 0 при отсутствии ошибок

#### Scenario: Успешная сборка с типами
- **WHEN** типы корректны и выполняется `npm run build`
- **THEN** проверка типов проходит и production-сборка создаётся как прежде (пути от `/react-bot-test/`, content hash, статика из `public/`)
